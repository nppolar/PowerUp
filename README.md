# PowerUp

**Less waiting, more editing.** A Lightroom Classic plug-in that makes moving to the next photo in Develop feel instant.

![Lightroom preloads 5 neighbouring photos on each side](https://iamnp.com/wp-content/uploads/sites/44132/2026/11/lr-powerup-1-preload.png)

**[Download PowerUp.zip](https://github.com/nppolar/PowerUp/releases/latest/download/PowerUp.zip)** · [Full guide (Thai)](https://iamnp.com/lightroom-powerup/)

## Install

1. Download **PowerUp.zip** (not "Source code") and unzip it. You get a folder called `PowerUp.lrplugin`. Move it somewhere permanent, such as Documents or Applications.
2. In Lightroom Classic, open **File › Plug-in Manager…**
3. Click **Add** and choose `PowerUp.lrplugin`.
4. A **PowerUp is ON** dialog appears. Click OK, then quit and reopen Lightroom.

## Turn it on or off

Use **Library › Plug-in Extras › PowerUp…** or **File › Plug-in Extras › PowerUp…**, then restart Lightroom.

To uninstall, click **Disable** in Plug-in Manager and restart Lightroom first, then click **Remove**. If you click Remove straight away, preloading stays on.

## Get the most out of it

Preloading works best when Lightroom has small files to load:

- **Import:** turn on **Build Smart Previews**. Set **Build Previews** to **Minimal** if you rarely zoom in Library.
- **Preferences › Performance:** turn on **Use Smart Previews instead of Originals for image editing**.

Export always uses the full-resolution originals. Only zooming to 1:1 or more in Develop loads the original file.

## Tested on

- Lightroom Classic 15.5 (macOS)
- Lightroom Classic 13.5 (Windows 10)

After each Lightroom update, open **PowerUp…** from Plug-in Extras to confirm it is still ON.
